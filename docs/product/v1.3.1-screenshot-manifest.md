# v1.3.1 固定截图清单

状态：Accepted  
日期：2026-07-24

## 固定视口

| 名称 | 尺寸 | 用途 |
|---|---:|---|
| Desktop | `1440×1000` | 完整导航、双栏详情和运营密度 |
| Tablet | `1024×900` | 收缩导航、详情侧栏和表格响应 |
| Mobile | `390×844` | 任务顺序、触控动作和助手对话框 |

## 核心页面

| 页面标识 | 路由 | 必须出现的事实或动作 |
|---|---|---|
| `support-home` | `/support` | 环境/账号、待关注服务、任务入口、最近订单 |
| `orders` | `/orders` | 搜索、状态筛选、商品、履约、售后信号 |
| `order-detail` | `/orders/<order-id>` | 商品、状态、下一步、物流、交易和助手入口 |
| `services` | `/services` | 进行中/历史切换、当前步骤和下一步 |
| `service-detail` | `/services/<service-id>` | 时间线、当前阶段、结果/依据和原会话 |
| `chat` | `/chat/<thread-id>` | 会话列表、绑定上下文、普通消息、结构化方案 |
| `admin-overview` | `/admin` | 业务运营、Agent 质量、系统健康 |
| `admin-data` | `/admin/data` | 目标客户、目录场景、影响摘要和幂等结果 |

每个页面分别生成 Desktop、Tablet 和 Mobile 截图，共 `8 × 3 = 24` 个目标。

## 生成规则

- 使用隔离数据库、固定目录版本和稳定账号。
- 先初始化全部目录场景，再通过公开产品旅程创建服务、审批和会话状态。
- 动画关闭或等待稳定状态；不包含随机时间、邀请码、密码、密钥和本机绝对路径。
- 截图保存到 Playwright 输出或本机验收目录，不把大体积运行产物提交仓库。
- 截图负责产品评审，结构、交互、权限和数据一致性由自动化断言负责。

## 其他页面冒烟

登录、注册、长期偏好、邀请、Run 列表/详情、Eval 和系统状态不进入 24 个核心截图，但必须在
三个固定视口完成无横向溢出、主要动作可达和标题可见的响应式冒烟。
