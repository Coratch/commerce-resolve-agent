## 验收目标

证明本次信息架构、产品文案和视觉系统重构没有改变订单、会话、退款审批、Memory、Agent Loop、
权限或业务数据边界，并为客户售后中心和 Agent 运营控制台提供可重复的产品评审证据。

- 固定目录：12 个商品、19 个 SKU、10 个订单场景。

## 边界

- 本版本没有新增数据库迁移、公开 API、Agent 权限、知识库或向量检索能力。
- 客户历史消息中的研发术语只在展示层转换，Checkpoint 和业务事实没有被改写。
- 退款继续使用演示资金、确定性 Policy、人工审批、幂等执行和结果回读。
- 真实 Provider 资格与 Docker Gate 独立报告，不因 UI 验收通过而被视为通过。
