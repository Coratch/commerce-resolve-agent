## 已知限制

- 订单、物流、支付、退款和 Case 均为本地 Mock 业务事实。
- SQLite 仅支持本地单实例目标，不代表 PostgreSQL 多实例生产能力。
- 后台 Run 使用进程内任务；进程退出后标记为 `interrupted`，由用户显式重试。
- 真实模型输出存在非确定性，Provider Qualification 必须与离线确定性门禁并行保留。
- 参考 Docker 运行验收按既有项目决策延后；本报告只声明部署 Bundle 静态检查通过。
- 多格式文件、OCR、向量数据库、Rerank 和多模态政策证据属于 V2.1。
