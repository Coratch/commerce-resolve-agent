## 真实 DeepSeek 冒烟

使用 `.env` 中现有 OpenAI-compatible 配置，在临时数据库创建注册用户、32 条公开消息和
`ORD-001`，经正式 SQLite Checkpointer 完成一条 L2 长上下文路径。

```text
decision path:       get_order -> get_shipment -> answer
result:              l2_resolved
trace_state:         complete
model_calls:         3
context_manifests:   3
public_trace_events: 11
usage_source:        provider
```

冒烟预检发现模型对 `answer` 字段名的遵循不稳定；在系统指令中补充所有 Decision 的精确 JSON
形状后重试通过。该调整没有放宽 Pydantic Schema，也没有把无效输出自动转换为有效动作。

## 数据与兼容

- `20260721_0005_v07_context_observability.py` 新增 Context Manifest、Case Trace 状态、事件
  单调序号、模型调用关联和指标字段。
- v0.5/v0.6 旧 Case 原地保留并标记为 `partial`，不从 Checkpoint 推测或补造 Manifest。
- 新模型调用必须先成功保存 Manifest；Manifest 写入失败时 Provider 调用数为 0。
- Manifest 只保存引用、版本、Disposition、计数和哈希，不保存完整 Prompt 或候选正文。
- 损坏或缺失的新版本 Manifest 会让 Trace 降级为 `unavailable`，读取路径不会写修复数据。

## 结论与限制

v0.7 发布门槛全部通过。L2 每次模型调用已有可验证 Context Pack 和先写 Manifest，页面可从
服务端恢复本人 Case 并只读分页 Trace，开发者可用 CLI 查看不含正文的诊断信息。

当前选择算法仍是确定性字符串、订单锚点与中文 bigram，不包含 Embedding、Rerank、自动摘要
或外部 Trace 平台；Context Token 为保守估算，Provider 未返回 Usage 时会明确标记估算来源。
SQLite 和进程内后台任务仍只适用于本地单实例学习环境。
