Completed。

## 8. 已知边界

- 单服务、单 worker、单机 SQLite，不支持多实例或在线热备份。
- 未完成 Run 只安全中断，必须由用户显式重试，不自动续跑未知副作用。
- Backup 需要短暂停机；政策索引、日志、Secret 和 Eval Artifact 不进入 Backup。
- 只支持固定 v0.8 到 v1.0 升级，不提供自动 Down Migration。
- 所有订单、物流、支付、退款和二线客服仍为本地 Mock/Fake 边界。
