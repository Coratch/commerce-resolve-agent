# CommerceResolve v0.3 Web、身份与私有数据 Eval 报告

状态：Passed  
日期：2026-07-17  
场景集：`v0.3`

## 评估范围

本报告验证从浏览器身份到既有 LangGraph 主图的完整边界：

- 游客只读 Fake 对话及零 LLM 调用。
- 邀请码、注册、登录、退出、过期 Session 和重复消费。
- 私有订单与物流 CRUD、工作区隔离和严格请求 Schema。
- 注册用户 LLM 授权、私有数据查询、政策 RAG、配额和失败不降级。
- conversation 归属、跨实例 Checkpoint 恢复和身份不匹配拒绝。
- React 组件、生产 SPA 静态托管和真实 Chromium 浏览器闭环。

离线发布门槛使用 Fake Interpreter、Spy Interpreter、临时 SQLite 和本地 ASGI，不访问
网络或真实 API Key。DeepSeek 只用于独立手工冒烟。

## 复现命令

```bash
conda activate ecom-agent
python -m pytest -q
python -m ruff check .
python -m ruff format --check .
python -m commerce_resolve eval --suite all

cd frontend
npm run typecheck
npm test
npm run build
npx playwright test
```

## 结论与限制

v0.3 证明了本地单实例范围内的 Web 身份、私有业务数据、模型授权和可恢复 Agent 闭环。
结果不能外推为生产多实例、安全审计认证或真实电商接入；账号和订单仍是本地演示数据，
也没有退款、Handoff、动态 Agent Loop、OAuth、找回密码或 MFA。
