## 评估范围

本报告使用真实 LangGraph 主图、Fake Query Interpreter、真实受控 Markdown/JSON
语料、临时 SQLite FTS5 索引和 Fake 订单/物流 Gateway，确定性验证：

- 相关政策章节召回。
- 事实、结论和服务端引用关系。
- 无证据拒答、缺失条件澄清和跨实例恢复。
- 当前有效政策冲突和过期版本隔离。
- 用户输入与政策原文 Prompt Injection 防护。
- 政策路径不调用订单、物流或任何业务写工具。

DeepSeek 仅用于三条独立手工冒烟，不参与离线发布分数。

## 真实模型冒烟

使用 `.env` 配置的 DeepSeek OpenAI-compatible Chat，显式选择
`--interpreter openai`，以下三条路径于 2026-07-17 通过：

1. “退款多久到账？” → `refund/timing`，返回单一来源。
2. “换货期限和条件是什么？” → `exchange/window+conditions`，返回两个来源。
3. “订单 ORD-001 能退款吗？” → 通用政策回答，并声明不判断具体订单资格。

真实模型只生成受限 `Interpretation` / `PolicyQuery`。最终 `claim_text`、事实选择和
引用仍由本地确定性代码生成；模型调用失败不会回退 Fake。

## 复现命令

```bash
conda activate ecom-agent
python -m commerce_resolve policy-index build
python -m commerce_resolve eval --suite v0.1
python -m commerce_resolve eval --suite v0.2
python -m commerce_resolve eval --suite all
```

任一门槛失败时 Eval 命令返回非零退出码。完整 JSON 包含逐场景状态、事实 ID、
章节 ID、引用与安全判断。

## 结论与限制

v0.2 证明了受控演示语料上的可解释词法 RAG 闭环，不代表真实电商平台政策完整性。
当前没有 Embedding、向量数据库、Rerank、具体订单资格判断或售后写操作；这些能力
不能从本报告的 100% 指标外推。
