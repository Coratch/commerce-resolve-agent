# Technical Plan：v1.3.2 沉浸式电商服务界面

状态：Implementation Complete / Owner Visual Review Required  
日期：2026-07-24  
对应 Spec：
[`../specs/v1.3.2-immersive-commerce-interface.md`](../specs/v1.3.2-immersive-commerce-interface.md)

## 1. 目标

在不修改业务 Schema、公开 API 和 Agent 权限的前提下，重构 React SPA 的品牌、图标、排版、
布局与动效系统，使客户售后中心具备沉浸式编辑体验，使运营控制台具备统一但高密度的控制室体验。

## 2. 技术选择

| 能力 | 选择 | 原因 |
|---|---|---|
| 图标 | `lucide-react` | 统一描边语言、可 Tree-shaking、React 类型完整、可访问性易控制 |
| 生成式视觉 | 原生 Canvas 2D | 不增加 WebGL 框架，足以实现指针响应流场并可精确控制生命周期 |
| 动效 | CSS Keyframes、Transform、单 RAF 循环 | 避免动画库和多循环，保持构建体积与 Reduced Motion 控制 |
| 版式 | CSS Grid、Subgrid 可降级布局、CSS 自定义属性 | 支持非对称构图和三视口，不改变组件数据职责 |
| 字体 | 本机系统字体栈 | 不产生远程请求、许可和离线失败 |
| 测试 | Vitest、Playwright、静态 Eval | 分别验证组件语义、真实旅程和跨文件设计契约 |

## 4. 垂直任务

### T1：规格、设计原则与基线

- 接受 v1.3.2 Spec。
- 把 v1.3.1 标记为工程通过但视觉方向未被项目所有者接受。
- 固化图标、Canvas、动效、响应式和业务边界。

状态：Completed

### T2：品牌、Lucide 与生成式交互基础

- 安装 `lucide-react`。
- 建立新 Token、客户外壳、品牌标记和唯一导航图标。
- 实现单 Canvas 流场、页面隐藏暂停、DPR 上限和 Reduced Motion。

状态：Completed

### T3：客户售后任务页面

- 重构首页、订单、服务、详情、对话、认证和长期偏好。
- 使用编辑式排版、非对称网格和业务图片建立层次。
- 清除字符箭头、汉字图标和 Emoji。

状态：Completed

### T4：Agent 运营控制台

- 重构侧栏、概览、数据、邀请、Run、Eval 与系统页面。
- 使用 Lucide、状态轨道和高密度信息面板。
- 保持所有运营页面只读/有限写边界。

状态：Completed

### T5：响应式、动效和无障碍

- 验证 1440×1000、1024×900、390×844。
- 验证键盘焦点、图标名称、Reduced Motion、Canvas 暂停和无横向溢出。
- 限制动画只使用 Transform/Opacity/Canvas，避免布局抖动。

状态：Completed

### T6：Eval 与回归

- 新增不少于 24 条固定视觉契约场景。
- 运行组件、构建、在线/离线 E2E、后端全量测试和统一 Eval。
- 检查敏感数据、OpenAPI、文档链接和代码注释。

状态：Completed

### T7：产品证据与收口

- 更新代码指南、目标地图、README 和版本报告。
