# Feature Spec：v1.3.2 沉浸式电商服务界面

状态：Accepted  
日期：2026-07-24  
接受依据：项目所有者明确要求按 Awwwards、FWA 与 CSS Design Awards 级别重构 UI  
依赖版本：v1.3.1 商业产品可信度重构（工程验收通过，视觉方向未接受）  
后续版本：v1.4 多模态政策知识与复杂问答（Proposed）

## 目标

把 CommerceResolve 从可信但保守的业务界面，重构为具有鲜明艺术指导、实验性排版、生成式背景、
物理感动效和完整品牌语言的沉浸式电商售后产品，同时继续完成订单、服务、对话、审批和运营任务。

本版本借鉴国际数字设计奖项对 UI、UX 与 Innovation 的综合要求，但不声称代码完成即可获得奖项。
“奖项级”被转换为可验证的视觉一致性、交互质量、性能、响应式、可访问性和业务任务门禁。

## 成功定义

1. 客户首次进入即可感知统一、独有的 CommerceResolve 艺术方向，而不是通用后台模板。
2. 全部界面图标来自 Lucide；客户和运营界面不使用表情符号或字符模拟图标。
3. 客户表面使用编辑式大字、非对称构图、生成式画布和有目的的物理动效，同时保留订单与服务任务。
4. 运营控制台共享品牌系统，但保持更高数据密度、清晰分组和键盘可达。
5. 页面动效不阻塞点击、输入、审批或路由；Reduced Motion 下关闭连续动画和位移。
6. 桌面、平板和移动端均无横向溢出，核心任务与主要动作可见。
7. 订单、退款、Memory、Agent Loop、权限和服务端数据契约保持不变。

## 产品艺术方向

### 视觉语言

- 基础色使用近黑墨色、暖白纸色、荧光青柠和信号橙，形成数字编辑部与服务控制室的统一语言。
- 字体使用本机可用的系统字体组合，不加载远程字体；标题采用超大比例、紧凑字距和错位基线。
- 版式允许非对称网格、纵向标签、超大序号、局部越界文字和分层面板，但正文与动作保持可读。
- 商品图片作为业务证据嵌入构图，不使用远程装饰图、竞品资产或无来源素材。
- 客户表面强调“服务流动”；运营表面强调“信号、证据和控制”。

### 交互语言

- 使用单个生成式 Canvas 绘制低密度流场、轨道与指针响应，不在每张卡片创建独立动画循环。
- 页面进入、导航、卡片和状态变化使用弹性缓动；按钮反馈不超过任务完成所需时间。
- 悬停、聚焦和选择状态同时通过形状、位置、文字和颜色表达。
- 页面隐藏、离屏或 Reduced Motion 时暂停连续动画。

### 图标规则

- 安装并使用 `lucide-react`。
- 导航、任务、状态、动作、空状态和运营模块只使用 Lucide 图标。
- 品牌字标、商品图片、状态圆点和纯装饰 CSS 图形不属于功能图标。
- 图标按钮必须具有可访问名称；装饰图标使用 `aria-hidden="true"`。
- 禁止在可见界面使用 Emoji、Unicode 图画符号或汉字方块模拟图标。

## 范围

### 客户售后中心

- 全局导航、品牌、账号和演示环境披露。
- 售后首页、订单列表/详情、服务列表/详情。
- 独立对话和上下文对话、退款确认、AI 二线记录。
- 登录、邀请注册和长期偏好。

### Agent 运营控制台

- 侧栏与移动导航。
- 运营概览、演示数据、邀请、Run、Eval 和系统状态。
- 只改变信息表达与视觉层，不增加后台写能力。

### 质量证据

- Lucide 唯一图标依赖和无 Emoji 静态门禁。
- Canvas 生命周期、Reduced Motion 和页面隐藏暂停测试。
- 三视口 E2E、键盘、焦点、无横向溢出和核心旅程回归。
- 更新后的固定截图、产品评审量表和版本报告。

## 非目标

- 不复制任何获奖网站的品牌、布局、源代码或视觉资产。
- 不引入 Three.js、WebGL 框架、视频背景、远程字体或运行时视觉服务。
- 不为视觉效果增加业务 API、数据库迁移、Agent 工具或模型权限。
- 不使用滚动劫持、不可关闭过场、音频自动播放或隐藏系统光标。
- 不让 Canvas、视差或动效阻止低性能设备完成售后任务。
- 不实施 v1.4 的上传、OCR、向量数据库、Embedding 或多模态检索。

## 验收条件

1. `frontend/src` 可见产品文案中的 Emoji 数量为 `0`。
2. 功能图标全部通过 `lucide-react` 渲染，字符箭头与汉字图标数量为 `0`。
3. 客户和运营外壳共享同一品牌 Token、图标规则和动效语义。
4. 生成式 Canvas 只有一个 `requestAnimationFrame` 生命周期，并限制设备像素比。
5. 页面不可见或 Reduced Motion 时连续动画停止。
6. Enter、Shift+Enter、SSE、刷新恢复和退款审批行为不变。
7. 三固定视口无横向溢出，移动端主要动作无需横向拖动才能发现。
8. 键盘焦点可见，图标按钮具有可访问名称，颜色不是状态唯一载体。
9. 前端组件测试、构建、在线/离线 E2E 和后端全量回归通过。
10. v1.3.2 固定视觉契约 Eval 与统一离线 Eval 通过，安全违规为 `0`。
11. `docs/codebase-guide.md`、截图清单和版本报告与最终实现一致。
12. 项目所有者基于真实页面完成最终视觉验收。
