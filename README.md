# CommerceResolve

基于 LangGraph 的可审计电商售后客服 Agent。

项目目标是围绕订单查询、物流跟踪、退款审批与人工客服转接，构建可持久化、可恢复、可评估的 Agent 工作流。

## 当前状态

项目已完成本地初始化，Feature Spec 与产品代码尚未开始。

## 计划能力

- 订单与物流查询
- 售后政策 RAG 与来源引用
- 退款预览、权限审批和幂等执行
- Human-in-the-loop 人工客服介入
- LangGraph Checkpoint 与跨进程恢复
- Agent Eval、审计、延迟与成本指标

## 开发原则

- LLM 负责理解诉求和提出候选动作，不直接决定退款资格、金额或授权。
- 资金相关动作必须经过确定性 Policy、审批、幂等执行和结果验证。
- 先完成最小端到端闭环，再按 Eval 结果增加复杂度。
